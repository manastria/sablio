# Sablio : préparer l'emploi du temps d'un élève

Notice pour l'ergothérapeute, l'enseignant ou toute personne qui prépare l'emploi du temps d'un ou plusieurs élèves sur son propre ordinateur, avant de l'envoyer à la famille.

## Le principe

Chaque élève a son Sablio, sur l'ordinateur familial (sa session Windows). Vous préparez son emploi du temps dans **votre** Sablio, puis vous l'**exportez** dans un fichier. La famille l'**importe** dans le sien.

Le fichier contient seulement l'emploi du temps : matières, activités, cours, rendez-vous, vacances, semaines alternées, prénom de l'élève. Il ne contient **ni les devoirs, ni le code du verrou**.

## Préparer un nouvel élève

1. Menu (☰) → **Emploi du temps et agenda**.
2. **Nouvel emploi du temps (vide)** : les matières sont gardées ; les cours, activités, événements et vacances repartent de zéro.
3. **Indiquer le prénom de l'élève** : il apparaît dans le titre et dans le nom du fichier exporté.
4. Saisissez :
   - les **cours** de la semaine type (« + Ajouter » sur chaque jour), avec les semaines A/B si besoin ;
   - les **activités** (orthophonie, psychologue, sport) et, pour chacune, ce qui s'affiche en **mode discret** (en classe, l'écran se voit) ;
   - la **zone de vacances** et les **semaines alternées** ;
   - les **rendez-vous** datés dans l'agenda.
5. **Exporter l'emploi du temps** : un fichier `sablio-emploi-du-temps-leo-2026-11-20.json` est enregistré.

## Envoyer le fichier

Transmettez-le comme une **donnée de santé** : il peut contenir des rendez-vous de soin. Préférez une remise en main propre (clé USB) ou une messagerie sécurisée.

## Côté famille

Menu → Emploi du temps et agenda → **Importer un emploi du temps…** → choisir le fichier.

- **Le remplacer** : l'emploi du temps du fichier remplace celui de l'ordinateur (cas habituel à la première installation).
- **Ajouter le fichier** : on garde l'existant et on ajoute ce qui manque.

Les matières de même nom et les cours identiques ne sont pas créés en double. Les devoirs déjà saisis sont conservés.

Si la configuration est verrouillée, l'import demande le code adulte.

## Plusieurs élèves, retouches

Gardez **un fichier par élève**. Pour reprendre un élève :

1. **Importer un emploi du temps…** avec son fichier, en le **remplaçant** ;
2. modifiez ;
3. **exportez** de nouveau et renvoyez le fichier.

Avant de passer à l'élève suivant, exportez toujours l'élève en cours : l'import ou « Nouvel emploi du temps (vide) » remplace ce qui est affiché.
