Code de demande :

Code adulte

Quatre chiffres. Ils seront demandés pour modifier l’emploi du temps, les séances, les réglages et les données. L’élève garde ses devoirs, peut ajouter des événements et basculer le mode discret.

Importer un emploi du temps

Que faire de l’emploi du temps actuel ?

Les matières de même nom sont reconnues (pas de doublon). Les devoirs ne sont pas touchés ; ceux rattachés à un cours retiré restent rattachés à leur date.

Passer à l’usage réel

Sablio s’est ouvert sur un exemple. Pour l’utiliser vraiment :

Ensuite : choisissez un dossier de sauvegarde (menu ☰), puis votre emploi du temps (menu ☰ → Emploi du temps et agenda).
