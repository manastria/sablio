Code adulte oublié

Dans Sablio, la fenêtre du code propose « Code oublié ? » et affiche un code de demande à six chiffres. Saisissez-le ici : vous obtiendrez un code de secours, valable aujourd’hui, qui ouvre le mode adulte. Choisissez ensuite un nouveau code.

Le calcul est public : ce code évite de rester bloqué après un oubli, il ne protège rien. Le verrou de Sablio sert à éviter les modifications par erreur ou par jeu.
